Getting Started

Leave Sync for YouTrack reads approved time off from Microsoft Teams Shifts through Microsoft Graph. Setup takes about 15 minutes. You connect a Microsoft Entra app registration once, then add your employees.

What you need

  • A YouTrack administrator account (permission to install apps).
  • A Microsoft 365 administrator who can register an app and grant admin consent (Global Administrator or Privileged Role Administrator).
  • A team in Microsoft Teams that uses Shifts for time-off requests.
  • For each employee: hire date, optional birth date, and how many leave days they have left today.

Try it first with demo data (optional)

You can try the app before connecting Microsoft 365:

  1. In Administration → Apps → Leave Sync for YouTrack → Settings, tick Use demo data (no Microsoft connection) and save. You can leave the Microsoft fields empty.
  2. In Administration → Integrations → Leave Management → Employees, add a few users with hire dates.
  3. Open Leaves in the main menu.

The app generates sample time off for every employee you add: vacations, a half day, hourly sick leave, upcoming leave and a schedule change that hasn't been shared yet. No data is sent anywhere. To switch to real data, untick the setting and follow Part 1. Demo mode doesn't delete anything: if you already use the app, your real leave, linked people and leave-type choices are only hidden while demo mode is on, and come back when you turn it off. Keep in mind that while it is on, everyone sees demo data on the Leaves page.

Part 1 – Connect Microsoft Teams

Step 1. Register an app in Microsoft Entra ID

  1. Sign in to entra.microsoft.com.
  2. Go to Identity → Applications → App registrations.
    Tip: if you land on Enterprise applications, open App registrations instead. You can use the application registrations link in the page description.
  3. Click + New registration and fill in:
    • Name: Leave Sync for YouTrack (any name works; it is only shown in Entra)
    • Supported account types: Accounts in this organizational directory only (Single tenant)
    • Redirect URI: leave empty
  4. Click Register. The app's Overview page opens.
  5. In Essentials, copy the Application (client) ID and the Directory (tenant) ID. You don't need the Object ID. These two IDs are not secret.

Step 2. Grant Microsoft Graph permissions

  1. In the app's left menu, under Manage, open API permissions.
  2. Click + Add a permission → Microsoft Graph → Application permissions.
    Choose Application permissions, not Delegated permissions. The app reads data in the background, without a signed-in user.
  3. Search for and select both permissions:
    • Schedule.Read.All: reads time off and time-off reasons from Shifts.
    • User.Read.All: matches Teams users to YouTrack users by e-mail.
  4. Click Add permissions.
  5. Click Grant admin consent for <your organization> and confirm with Yes. Both permissions must show a green check and Granted for <your organization>. You can keep the default User.Read (Delegated) permission.

Step 3. Create a client secret

  1. Under Manage, open Certificates & secrets. You can also click Add a certificate or secret on the Overview page.
  2. On the Client secrets tab, click + New client secret. Enter Description: YouTrack and set Expires: 24 months.
  3. Click Add and copy the Value right away.
    • Copy the Value column, not the Secret ID column.
    • The value is shown only once. Treat it like a password.
  4. Add the expiry date to your calendar. Before it expires, create a new secret and update the app settings in YouTrack.

Step 4. Find your Team ID

  1. In Microsoft Teams, open the team that uses Shifts. To check which team that is, open the Shifts app: it shows the team whose schedule you are viewing.
  2. Open the team's ⋯ menu (next to the team name, or at the top right of the team page). Select Copy link (in older Teams: Get link to team) and click Copy.
  3. Paste the link somewhere. The Team ID is the value after groupId=, up to the next &. For example, in
    …/conversations?groupId=1a2b3c4d-1111-2222-3333-444455556666&tenantId=…
    the Team ID is 1a2b3c4d-1111-2222-3333-444455556666.
    • Don't use the 19%3A…thread.tacv2 part of the link. It is a different identifier.
    • The tenantId in the link must match the Directory (tenant) ID from Step 1.
  4. Alternative: in Entra → Groups → All groups, open the team's group. Its Object ID is the Team ID.
  5. If you use Shifts in more than one team, collect each Team ID.

Step 5. Enter the connection in YouTrack

  1. In YouTrack, go to Administration → Apps and select Leave Sync for YouTrack. Check that the Active toggle is on.
  2. Open the Settings tab:
    • Visibility: keep the app available to all users, so everyone sees the Leaves menu item.
    • Microsoft Entra tenant ID: the Directory (tenant) ID from Step 1.
    • Application (client) ID: from Step 1.
    • Client secret: the secret Value from Step 3.
    • Teams team IDs: from Step 4. Separate several IDs with commas.
    • Leave administrators group (optional): members can manage employees and see everyone's leave. System administrators always can.
  3. ⚠️ Watch out for browser autofill. Check every field before you save. Browsers often put your e-mail address into tenant ID and a saved password into Client secret. If that happened, clear both fields and paste the correct values. If the browser offers to save a password, choose Never.
  4. Click Save and reload the page. You now have:
    • Leaves in the main menu, for every user.
    • Leave Management under Administration → Integrations, for administrators.

Step 6. Test the connection

  1. Open Administration → Integrations → Leave Management → Teams connection and click Sync now.
  2. When the connection works, you see Last sync: just now · N leave items since <date>. About the last 13 months of approved time off is read.
    • 0 people updated is normal at this point. Leave is only stored for employees you add in Part 2.
    • If a red Last Teams sync failed message is shown, see Troubleshooting below. After fixing the settings, click Sync now again.

Part 2 – Configure leave

All of these steps are in Administration → Integrations → Leave Management.

  1. Leave types: the time-off reasons from Teams are listed here. Tick the ones that are deducted from annual leave (usually Off / vacation) and click Save. Unticked types are counted and shown, but not deducted. Check local law before ticking sick-leave types.
  2. Holidays & working time:
    • Under Public holidays and days off, add this year's public holidays and company days off with + Add day. Tick Half day for days that are only half off. This is optional, but a leave that spans a holiday is only counted correctly if the holiday is in the list.
    • For the next year, pick it in Year and click Copy … to …, then correct the dates of holidays that move every year (for example Easter or religious holidays).
    • Set your company's UTC offset (winter time; a new installation starts at 0) and Daylight saving time. For example, Germany: 1 and EU summer time; Türkiye: 3 and None.
    • Check the working hours per day (default 8) and the non-working days (default Sat/Sun).
    Weekends and holidays are never deducted, and half-day holidays count as half a day.
  3. Entitlement rules: set the annual leave by years of service to your company's policy (the starting values are 1–5 years: 14, 6–14 years: 21, 15+ years: 26 days), and turn the optional age rule on or off.
  4. Employees → + Add employee: pick the person, enter the hire date and click Add. Their leave is loaded from Teams right away. Then, in the right panel:
    • Under Remaining today, enter how many days the person has left today and click Calculate. This is the easiest way. Future approved leave is deducted when it happens.
    • Count Teams leave from is set automatically. For people hired within roughly the last 13 months it is the hire date, so leave taken in the first year is deducted from their first entitlement.
    • Leave the Entitlement field in Leave years empty to use the automatic value. Type a number only to override one year.
    • Tick Checked and confirmed and click Save profile.
  5. Teams connection → People in Teams not matched to YouTrack: people are matched by e-mail. Link anyone listed here to the right YouTrack user, then click Sync now. An entry shown as Unknown is usually a deleted or guest account.

Part 3 – Check

  • Open Leaves → View → Team overview and compare a few balances with your own records.
  • Ask an employee to open Leaves. They should see only their own data, with no View picker.

Feature guide – what each part does

Leaves page (main menu, every user)

  • Show: chooses the period you look at:
    • Leave years: one work anniversary to the next. This is the balance view.
    • Calendar years: for example Calendar year 2026.
    • Custom date range: any from and to dates you pick.
  • Remaining annual leave: days and hours left in the current leave year. Red means the balance is negative (leave taken in advance).
  • Entitlement this year: days granted on the last work anniversary, based on years of service.
  • Carried over: unused leave from earlier leave years.
  • Used (annual leave): leave of types that are deducted from annual leave.
  • Adjustments: days a manager added or removed by hand, each with a reason.
  • Usage by type: all leave in the period grouped by Teams reason. Each type shows whether it counts against annual leave.
  • Leave history: every leave in the period with the time charged. Labels:
    • upcoming: approved leave in the future.
    • Corrected: a manager changed how much is counted. The note is shown.
    • Updated by manager: changed in the Shifts schedule.
    • Before tracking: older than the tracking start, already included in the carried-over balance.
  • For calendar years and custom ranges, the cards show the leave inside the chosen dates: annual leave, other leave and the total. The remaining balance always refers to the current leave year.

View picker (administrators only, on the Leaves page)

  • My leave: your own page.
  • Team overview: one row per employee.
    • Columns: remaining leave now, annual leave used, other leave, and one column per leave type, with team totals. Values are in days.
    • The period can be each person's current leave year, a calendar year or a custom range.
    • Click a row to open that person.
  • An employee's name: opens that person's Leaves page exactly as they see it. This view is read-only. Changes are made in Leave Management.

Leave Management → Employees

  • Employee list: hire date, years of service, this year's entitlement, used and remaining days. Check balance marks people whose starting balance hasn't been confirmed yet.
  • Profile:
    • Hire date: sets the leave year (anniversary to anniversary) and the years of service.
    • Birth date: optional. Only used for the age rule.
  • Count Teams leave from: Teams leave before this date is ignored, because it is already included in the carried-in balance. People hired within roughly the last 13 months start at the hire date, so leave taken before their first entitlement is deducted from it.
  • Balance carried into <date>: unused leave from before the tracking start. Use the automatic value or type your own, then tick Checked and confirmed.
  • Remaining today → Calculate: the quickest way to set the balance. Enter what the person has left today and the carried-in balance is worked out for you.
  • Leave years: one row per leave year showing carried in, entitlement, adjustments, used and remaining. Type a number in Entitlement to override one year; leave it empty for the automatic value.
  • Manual adjustments: add or remove days or hours with a reason, for example leave taken outside Teams or extra days granted. The date decides which leave year it belongs to. The employee sees the reason.
  • Leave from Teams: every leave imported for the person.
    • The period selector shows the last month and upcoming leave by default. You can switch to 3 months, upcoming only, leave year, calendar year, all, or a custom range.
    • Correct changes how much of a single leave is counted, or excludes it. Reset to Teams removes the correction.
    • The not shared in Teams label means the leave was changed in the Shifts schedule but not shared with the team yet.
  • Stop tracking: removes the person from the list and from the Leaves page. Their data is kept, and adding them again brings it back.

Leave Management → other tabs

  • Leave types: the time-off reasons from Teams. Tick the ones deducted from annual leave. Unticked types are only counted. New reasons appear as Needs review and are not deducted until you review them.
  • Holidays & working time:
    • Hours per working day, used to turn hourly leave into days.
    • Non-working days.
    • Company time zone: UTC offset plus optional EU summer time, so all-day leave always falls on the right date.
    • Public holidays and days off: the holidays and company days off you enter, shown one year at a time. Leave on these days is not deducted, and Half day counts as half a working day. Copy … to … copies the previous year's days as a starting point.
  • Entitlement rules: days of annual leave by years of service, plus an optional minimum for young and older employees (needs a birth date).
  • Teams connection:
    • Sync now, and the automatic refresh interval. Data is refreshed when someone opens Leaves and it is older than the interval.
    • Count changes made in the Shifts schedule right away: on by default. When it is off, only what employees see in Teams counts.
    • Linking people whose e-mail differs between Teams and YouTrack.
  • Change history: who changed what and when, for profiles, balances, adjustments, corrections and settings.

When the leave in Teams is wrong

  • Preferred: fix the time off in the Shifts schedule, then click Share with team. Your change counts at the next sync even before you share it, and is marked not shared in Teams until you do.
  • Otherwise: go to Leave Management → Employees → the person → Leave from Teams → Correct. Charge a different number of days or hours, or don't count the leave at all. A note is required and the employee sees it. The correction stays in place after every sync until you click Reset to Teams.

Troubleshooting

  • AADSTS900023 … tenant identifier '<e-mail>': the browser autofilled your e-mail into the tenant ID field. Enter the Directory (tenant) ID and re-enter the client secret (Step 5).
  • AADSTS7000215 / invalid client secret: the Secret ID was copied instead of the Value, a password was autofilled, or the secret expired. Paste the Value again, or create a new secret.
  • HTTP 401 / 403 from Microsoft Graph: admin consent is missing, or Delegated permissions were added instead of Application permissions (Step 2).
  • HTTP 404 for a team: wrong Team ID (for example, the 19:…thread.tacv2 part was used), or the team has no Shifts schedule (Step 4).
  • The error is still shown after fixing the settings: it is the result of the previous attempt. Click Sync now and reload.
  • "Your leave profile is not set up yet": the user hasn't been added on the Employees tab. This applies to admins too.
  • A person's leave is missing: their e-mail differs between Teams and YouTrack. Link them on the Teams connection tab.
  • Leave marked "before tracking": it is before the Count Teams leave from date. Pick an earlier date, or include that leave in the balance.
  • Leave shows as "not deducted": the leave type isn't ticked on the Leave types tab.

Ongoing administration

  • New employee: Employees → Add employee.
  • Employee leaves the company: select them → Stop tracking. Their data is kept.
  • Every year: add next year's public holidays (Holidays & working time → Year → Copy, then check the dates that move).
  • New reason in Teams: review it on the Leave types tab, where it is marked Needs review.
  • Before the client secret expires: create a new one in Entra and update the app settings.
  • Updating the app: install the new version over the existing one. Don't delete the app: deleting it removes all of its data.
